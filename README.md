# Freelancer Matching Engine

A Java-based freelancer–company matching system designed to demonstrate
the practical application of core data structures and algorithms.

## Overview

The Freelancer Matching Engine connects companies with suitable
freelancers based on their skills and experience. The project uses
multiple data structures to efficiently manage users, match candidates,
and maintain hiring records.

## Features

- Add and manage freelancer profiles
- Add and manage company requirements
- Match freelancers based on required skills
- Select candidates based on experience
- Track hiring records
- Maintain rejected candidates
- Search and manage user information efficiently

## Data Structures Used

- **Binary Search Tree (BST)** – for organizing and managing skills
- **HashMap** – for efficient user lookup
- **PriorityQueue** – for prioritizing candidates based on experience
- **Stack** – for maintaining rejected candidates
- **ArrayList** – for storing and managing hiring records

## Technology

- Java
- Data Structures & Algorithms
